# K Row Balance v2 検証記録

2026-11-04。初版の型チェックエラーに対する修正と、強度・ブロック選択の拡張です。

ComfyUIコアのCPU契約テストを有効にした全体試験は **133 tests / 377 subtests成功**。
既存解析側は172 tests成功。compileallと差分の空白検査も成功しました。
独立レビューでは実装上の重大・中程度の問題はなく、初版検証記録との区別を明示しました。

## 変更と根拠

- `type(model) is ModelPatcher`による一律拒否をやめ、通常の派生型を受理。
- 動的入力はComfyUIの `get_non_dynamic_delegate()` で通常のpatcherへ変換。
  このAPIはネイティブのclone/reloadとdelegateキャッシュを使います。
- CPUテストharnessでは実際のネイティブdelegate/cloneメソッドを使用し、
  cached loaderの1回だけの呼び出し、設定保持、切り戻し、missing loaderの明確な失敗を確認。
  GPU Dynamic本体のload/forwardを実行したテストとは区別します。
- `strength=-10～10`、`max_change=0～0.95`。既定0/.03と旧block41の動作を保持。
- `blocks`は任意の0～41のカンマ/範囲指定。全対象の準備後に1つのcloneへまとめて登録。
  非選択blockを保持し、途中失敗で一部だけを元モデルへ反映しないことをテスト。

## 実チェックポイントの10ブロックを使うCPU projection試験

対象: `0,1,2,22,24,26,30,31,40,41`。設定: strength±2、cap0.3。
全ブロックでINT8コード/QV scale保持、Q/V出力一致、無変更・再構成対照の全QKV出力一致。
読み出すのは指定QKVだけで、フルモデル・VAE・text encoder・画像生成は実行していません。
