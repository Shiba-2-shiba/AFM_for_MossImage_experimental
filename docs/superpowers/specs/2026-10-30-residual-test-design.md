# MOSS Image Residual Test

全42 joint blockを3個ずつ（0–2、3–5、…、39–41）の14区間へ分け、
区間ごとに倍率を変更できる別ノードを追加する。全入力の既定値は1.0、範囲0～2、刻み0.01。
元のMOSS Image Residualと既存ワークフローはそのまま維持する。

## 設計判断

- 3ブロック刻みを採用する。42を余りなく分割でき、4ブロック刻みより変更対象を狭くできる。
- 1ブロックずつの42入力や自由入力の範囲指定は、今回の操作感より煩雑なため採用しない。
- `MossImageResidualTest` / `MOSS Image Residual Test`を既存カテゴリへ追加する。
  `blocks_00_02`から`blocks_39_41`までの14個のFLOAT入力を常時表示する。
- `ResidualTestConfig`は14個の名前付き倍率を保持し、既存の残差gateパッチと
  `install_residual`を共有する。1.0の区間にはパッチを登録しない。
- Attention＋MLP、LoRA後、両CFG、画像・テキスト、全ステップという作用範囲は既存と共通。
  LoRA → Residual Test → AFMの順序と、重複／未知パッチの拒否も維持する。
- 区間外のblockを直接変更しないことを保証する。生成画像の副作用低減や画質向上は
  プロンプト・モデル・倍率次第であり、今回の実装だけでは保証しない。

## 検証と範囲

全14区間の独立性、全1.0の完全なno-op、入力検証、native V3スキーマとAPI受付、
小型42層モデルで出力投影を直接倍率変更した独立参照との比較、AFM合成を検証する。
追加依存や独自JSは不要。実画像の最適倍率探索とsmoke helperの新ノード対応は今回の範囲外。

ユーザーの自律実行指示に従い、既存インストール先で実装・検証する。
設計判断は実装担当によるもの。承認待ち、コミット、公開、ComfyUIの再起動は行わない。
